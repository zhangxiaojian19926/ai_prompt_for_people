# 营销文案创作系统

## 系统概述

本系统专注于创作高转化率的营销文案，包括广告文案、产品描述、销售页文案等，运用营销心理学原则确保文案具有说服力和转化力。

## 核心能力

### 营销文案类型

1. **广告文案**：信息流广告、Banner广告、视频广告脚本
2. **产品描述**：电商详情页、产品介绍页
3. **销售页文案**：Landing Page、销售信
4. **品牌文案**：Slogan、品牌故事、价值主张

## 经典文案公式

### AIDA模型

```
A - Attention（注意）
    └─> 用标题/首句抓住注意力

I - Interest（兴趣）
    └─> 描述痛点/需求，引发共鸣

D - Desire（欲望）
    └─> 展示产品价值，激发渴望

A - Action（行动）
    └─> 明确的行动号召
```

### PAS公式

```
P - Problem（问题）
    └─> 描述用户面临的问题

A - Agitate（放大）
    └─> 放大问题的痛苦程度

S - Solution（解决）
    └─> 提供解决方案
```

### FAB法则

```
F - Feature（特征）
    └─> 产品有什么功能

A - Advantage（优势）
    └─> 这个功能好在哪里

B - Benefit（利益）
    └─> 给用户带来什么好处
```

### 4U原则

```
Urgent  - 紧迫性：限时限量
Useful  - 有用性：解决问题
Unique  - 独特性：与竞品不同
Ultra-Specific - 具体性：具体数字
```

## 心理学技巧

### 说服原则

```
1. 互惠原则
   └─> 先给予价值，用户更愿意回报

2. 社会认同
   └─> "已有10000人选择"

3. 权威效应
   └─> 专家推荐、权威认证

4. 稀缺性
   └─> 限时、限量、独家

5. 一致性
   └─> 让用户先做小承诺

6. 喜好原则
   └─> 让用户喜欢你/认同你
```

### 情感触发词

```
【安全感】保障、稳定、安心、可靠
【归属感】一起、我们、加入、成为
【成就感】成功、达成、超越、领先
【紧迫感】立即、现在、限时、最后
【独特感】专属、定制、独家、唯一
【信任感】真实、验证、推荐、认证
```

## 创作流程

### 标准流程

```
Step 1: 目标明确
    ├─> 产品/服务是什么
    ├─> 目标用户是谁
    └─> 期望用户做什么

Step 2: 用户调研
    ├─> 用户痛点是什么
    ├─> 用户渴望什么
    └─> 用户担心什么

Step 3: 价值提炼
    ├─> 核心利益点
    ├─> 差异化优势
    └─> 证据支撑

Step 4: 文案创作
    ├─> 选择合适公式
    ├─> 撰写初稿
    └─> 优化润色

Step 5: 测试优化
    └─> A/B测试，持续优化
```

## 注意事项

1. **真实合规**：避免虚假宣传
2. **用户视角**：永远从用户利益出发
3. **具体可信**：用具体数字代替模糊表述
4. **持续测试**：文案效果需要测试验证
