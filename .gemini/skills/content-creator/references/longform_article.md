# 长文与通讯创作系统

## 系统概述

本系统专注于创作深度文章、Newsletter通讯、博客长文等需要完整结构和深入论述的内容，确保内容有深度、有价值、有传播力。

## 核心能力

### 支持的内容类型

1. **深度文章**：行业分析、趋势观察、深度报道
2. **Newsletter通讯**：定期订阅内容、精选推荐
3. **博客长文**：个人观点、经验分享、教程指南
4. **专栏文章**：固定栏目、系列内容

## 文章结构框架

### 框架1：问题-分析-解决方案

```markdown
# [标题]

## 引言
[引出问题，激发读者兴趣]

## 问题定义
[清晰描述问题的本质和表现]

## 原因分析
[深入分析问题产生的原因]

## 解决方案
[提供具体的解决方法]

## 行动建议
[给读者的具体行动指南]

## 结论
[总结核心观点]
```

### 框架2：叙事-观点-洞察

```markdown
# [标题]

## 故事开场
[用故事或案例引入话题]

## 背景铺垫
[提供必要的背景信息]

## 核心观点
[阐述你的主要观点]

## 论据支撑
[用事实、数据、案例支撑]

## 深层洞察
[挖掘更深层的意义]

## 思考延伸
[引发读者进一步思考]
```

### 框架3：What-Why-How

```markdown
# [标题]

## What：是什么
[定义和描述]

## Why：为什么重要
[价值和意义]

## How：如何做
[具体方法和步骤]

## 总结
[核心要点回顾]
```

## 写作技巧

### 开头技巧

```markdown
【故事法】
三年前，我做了一个决定...

【数据法】
调查显示，90%的人都在这件事上犯错...

【问题法】
你有没有想过，为什么...？

【反常识法】
大多数人认为...但事实恰恰相反。

【引用法】
"..." ——某专家
这句话改变了我对XX的看法。
```

### 论述技巧

```markdown
【金字塔原则】
结论先行 → 分论点1 → 分论点2 → 分论点3

【MECE原则】
分类完整、互不重叠

【举例说明】
抽象观点 → 具体案例 → 回归观点

【对比论证】
正面案例 vs 反面案例 → 得出结论
```

### 结尾技巧

```markdown
【总结回顾】
最后总结一下，本文的核心观点是...

【行动号召】
如果你认同这个观点，下一步可以...

【开放思考】
这只是我的一点思考，你怎么看？

【金句收尾】
正如XXX所说，"..."
```

## 创作流程

### 标准流程

```
Step 1: 选题确定
    └─> 明确主题和目标读者

Step 2: 框架搭建
    └─> 选择合适的结构框架

Step 3: 素材收集
    └─> 案例、数据、引用

Step 4: 初稿写作
    └─> 按框架填充内容

Step 5: 润色修改
    └─> 优化表达、检查逻辑

Step 6: 标题优化
    └─> 最后确定标题
```
