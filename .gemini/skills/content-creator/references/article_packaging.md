# 文章打包输出系统

## 核心使命

为每篇文章创建独立目录，包含完整的文章内容和配图资源，确保文章可直接用于发布。

## 适用场景

| 平台 | 配图需求 | 目录结构 |
|------|---------|---------|
| 微信公众号 | 封面图 + 正文配图 | `article/` + `images/` |
| 知乎专栏 | 封面图 + 正文配图 | 同上 |
| 头条号 | 封面图 + 正文配图 | 同上 |
| 博客 | 封面图 + 正文配图 | 同上 |

## 输出目录结构

### 标准目录结构

```
articles/
└── YYYY-MM-DD_文章标题/
    ├── README.md           # 文章元信息
    ├── article.md          # 文章正文
    └── images/
        ├── cover.jpg       # 封面图
        ├── 01_section1.jpg # 正文配图1
        ├── 02_section2.jpg # 正文配图2
        └── ...
```

### README.md 模板

```markdown
# 文章信息

## 基本信息
- **标题**：[文章标题]
- **创建时间**：YYYY-MM-DD HH:mm
- **目标平台**：[微信公众号/知乎/头条]
- **字数**：约 X 字
- **预计阅读时间**：X 分钟

## 配图清单
| 图片文件 | 用途 | 插入位置 | 来源 |
|---------|------|---------|------|
| cover.jpg | 封面图 | 文章头部 | [来源说明] |
| 01_section1.jpg | 配图 | 第一节 | [来源说明] |
| ... | ... | ... | ... |

## 发布检查清单
- [ ] 文章内容已审核
- [ ] 配图已下载到本地
- [ ] 图片版权已确认
- [ ] 格式适配目标平台
```

## 配图规范

### 图片类型

| 类型 | 尺寸建议 | 用途 |
|------|---------|------|
| **封面图** | 900×383 (公众号) | 文章头部 |
| **正文配图** | 宽度≥600px | 内容说明 |
| **信息图** | 宽度≥800px | 数据可视化 |
| **人物图** | 宽度≥400px | 人物介绍 |

### 配图来源

1. **AI生成图片** - 使用 `generate_image` 工具生成
2. **网络搜索** - 使用 `search_web` 搜索相关图片
3. **截图** - 使用浏览器工具截取网页内容
4. **用户提供** - 用户自备图片素材

### 配图命名规范

```
封面图：cover.jpg
正文图：序号_描述.jpg

示例：
- cover.jpg
- 01_elon_musk_portrait.jpg
- 02_spacex_rocket.jpg
- 03_tesla_factory.jpg
- 04_first_principles_diagram.jpg
```

## 工作流程

### Phase 1：创作文章

1. 根据主题创作完整文章
2. 在需要配图的位置标注 `[配图：描述]`
3. 确定封面图需求

### Phase 2：规划配图

分析文章内容，确定配图需求：

```markdown
## 配图规划

### 封面图
- 主题：[描述]
- 风格：[写实/插画/信息图]
- 关键元素：[必须包含的元素]

### 正文配图
1. 位置：第X节 | 描述：[描述] | 类型：[人物/场景/图表]
2. 位置：第X节 | 描述：[描述] | 类型：[人物/场景/图表]
...
```

### Phase 3：获取配图

根据配图规划，通过以下方式获取图片：

#### 方式1：AI生成
```
使用 generate_image 工具生成配图：
- 输入：详细的图片描述提示词
- 输出：生成的图片文件
```

#### 方式2：网络搜索
```
使用 search_web 搜索相关图片资源：
- 搜索词：[主题] + [图片类型]
- 筛选：高清、无版权问题
```

#### 方式3：浏览器截图
```
使用浏览器工具访问相关网页：
- 截取所需内容
- 保存为本地文件
```

### Phase 4：组装打包

1. 创建文章目录
2. 保存文章正文
3. 下载/生成配图到 images/ 目录
4. 创建 README.md 元信息
5. 在文章中插入图片引用

## 文章图片引用格式

### Markdown格式（通用）

```markdown
![封面图](./images/cover.jpg)

## 第一部分

正文内容...

![配图说明](./images/01_description.jpg)

正文继续...
```

### 公众号格式说明

公众号编辑器需要手动上传图片，在文章中标注位置：

```markdown
[插入图片：images/cover.jpg - 封面图]

## 第一部分

正文内容...

[插入图片：images/01_description.jpg - 配图说明]
```

## 质量检查清单

### 目录结构
- [ ] 是否创建了独立的文章目录？
- [ ] 目录命名是否包含日期和标题？
- [ ] images/ 子目录是否存在？

### 文章内容
- [ ] 文章是否完整？
- [ ] 配图位置是否标注？
- [ ] 图片引用路径是否正确？

### 配图质量
- [ ] 封面图是否准备好？
- [ ] 正文配图是否齐全？
- [ ] 图片分辨率是否足够？
- [ ] 图片命名是否规范？

### 元信息
- [ ] README.md 是否包含完整信息？
- [ ] 配图清单是否完整？
- [ ] 来源是否标注？

## 常见陷阱

- ❌ **忘记创建目录**：直接输出文章不创建目录结构
- ❌ **配图路径错误**：图片引用路径不正确
- ❌ **配图缺失**：只标注位置但不实际获取
- ❌ **版权问题**：使用有版权争议的图片
- ❌ **命名混乱**：图片命名不规范难以管理
