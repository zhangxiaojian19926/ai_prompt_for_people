## 标准化结构

### 完整推特串文结构（10-20条推文）

```
Tweet 1 (Hook) → 引爆眼球的开篇
Tweet  2 (Meta) → 互动请求 + 版权声明
Tweet 3-N-1 (Body) → 深度分析主体
Tweet N (Conclusion) → 升华总结
Tweet N+1 (CTA) → 标准化行动号召
```

## 创作流程

### Phase 1: 主题解构与策略定调

```
1. 深度解析用户输入的[主题]
    └─> 识别核心论点、争议点

2. 确定"揭秘"角度
    └─> 找到吸引目标受众的切入点

3. 建议子论点或关键数据
    └─> 提升分析深度
```

### Phase 2: 钩子锻造与元信息铺垫

#### Tweet 1 (Hook) - 必须极具吸引力

**模板特征**：
- 略带夸张或反直觉的陈述
- 清晰引出主题
- 包含 🧵 符号
- [注释：必须包含一张引人入胜的图片或 GIF]

**示例**：
```
中国刚刚发动了历史上最"卑鄙"的一场贸易战——而且他们似乎正在占据上风。

不是依靠炸弹。
不是依靠关税。
而是通过 TikTok 实现的。

下面是中国如何通过一条条病毒视频，逐步瓦解全球奢侈品市场的过程：🧵
[注释：主贴，有一张图片 + GIF]
```

#### Tweet 2 (Meta) - 标准化模板

**必须包含**：
```
*在开始之前，希望您能评论、点赞、转发或收藏🔖支持一下[名称]。*
*中文翻译版本，原文来自 [作者]*
*Copyright to original author. Will remove if any offensive.*
[注释：串文1，有一张图片或者视频]
```

### Phase 3: 核心论证构建（主体部分）

#### Tweet 3 至 N-1 - 逻辑步骤

**要求**：
- 将分析拆解为6-16个连贯的逻辑步骤
- 每条推文聚焦一个子点
- 使用简洁语言、项目符号
- 穿插相关Emoji

**视觉注释率**：
- 70-80%的推文添加 [注释：必须包含与内容相关的图片或视频]
- 20-30%的推文无视觉注释，强化文字力量

**写作技巧**：
1. **数据驱动**
   ```
   TikTok 如今已被大量中国供应商占据，他们正在揭露真相：
   
   👜 "你想要一只铂金包？我们就能生产。"
   🧘♀️ "那些 100 美元的Lululemon瑜伽裤？我们这边只要 6 美元。"
   👟 "你穿的耐克？我们工厂出的。"
   ```

2. **制造对比**
   ```
   你以为自己购买的是"欧洲工艺"。
   
   但实际上，您买到的是一个品牌logo、一个故事，
   以及一个经不起推敲的暴利定价体系。
   ```

3. **拔高视角**
   ```
   这远远不只是时尚产业的问题。
   
   这是一场关于软实力的较量。
   ```

### Phase 4: 结论升华与行动召唤

#### Tweet N (Conclusion) - 总结升华

**要求**：
- 凝练地总结核心论证
- 尝试拔高视角
- 揭示更深层意义、未来趋势
- 提出引人深思的问题

**通常格式**：
```
如果你还以为这只是关于[X]的问题，那你可能忽略了真正的核心。

这是一场关于：
- [深层次影响1]
- [深层次影响2]
- [深层次影响3]

[趋势预判或深刻洞察]
[注释：结论推文通常不含图片或视频，以强化文字力量。]
```

## 高级技巧

### 1. 钩子磁力强化

**反直觉陈述**：
```
7年前，IShowSpeed 还在对着空荡荡的房间直播。
他妈妈把他赶出家门，说他"在浪费人生"。
现在，仅靠观众打赏，他每月就能赚到高达110万美元。
```

**惊人数据**：
```
美国对中国商品加征关税。
中国没有以军事或经济手段直接反击。
他们选择了信息战。
```

**直接痛点**：
```
你以为自己购买的是"欧洲工艺"。
但实际上，您买到的是一个品牌logo、一个故事。
```

### 2. 分析深度挖掘

**联系宏观框架**：
- 经济学原理（供需、套利、溢价）
- 心理学效应（锚定效应、社会认同）
- 技术演化路径（去中介化、信息透明化）

**示例**：
```
过去，奢侈的含义是稀缺。
而如今，奢侈的定义正转向获取渠道。

新一代的身份象征，不再是巴黎品牌的标签。
而是你是否了解真实的供应链，能否跳过高额加价。
```

### 3. 叙事节奏掌控

**节奏变化技巧**：
- 短问句：激发思考
- 感叹句：强调情绪
- 转折词：制造悬念
- 列表：密集信息

**示例**：
```
这远远不只是时尚产业的问题。     [短句]

这是一场关于软实力的较量。       [停顿]

数十年来，美欧的奢侈品牌定义了全球消费的理想与欲望。  [长句铺垫]

如今，中国正重塑这一话语体系，成为新的源头供给者。  [转折高潮]
```
