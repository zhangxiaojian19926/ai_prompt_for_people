# 书籍/论文深度分析提示词

## 核心使命

对书籍、论文或学术资料进行专业、严谨的深度解析和结构化重述，帮助学习者快速掌握核心知识并能实际应用。

## 分析框架

### 📖 第一部分：宏观层

#### 1.1 核心主旨
- 写作目的：作者为什么写这本书？想解决什么问题？
- 核心问题：本书试图回答的根本问题是什么？
- 关键结论：作者得出的最重要结论（列举全部）
- 一段话精华：如果只能用一段话概括这本书，是什么？

#### 1.2 全书框架总览
- 结构地图：用树状图或大纲形式展现章节结构
- 逻辑主线：各章节之间的逻辑关系和递进脉络
- 阅读路径建议：
  - 快速了解路径
  - 标准学习路径
  - 深度研究路径

#### 1.3 价值定位
- 领域地位：这本书在其领域的位置和重要性
- 目标读者：最适合谁读？需要什么基础？
- 独特贡献：相比同类书籍的独特价值

### 💎 第二部分：知识精华层

#### 2.1 核心概念体系

对每个一级概念进行深入分析：

```
概念名称
├── 定义
│   ├── 正式定义
│   ├── 通俗解释
│   └── 关键词解析
├── 内涵与外延
│   ├── 核心特征
│   ├── 本质属性
│   └── 价值意义
└── 概念演化
    ├── 历史起源
    ├── 发展脉络
    └── 未来趋势
```

#### 2.2 概念关系网
- 层级关系：上下位关系
- 因果关系：原因-结果链
- 对立/互补关系

#### 2.3 核心观点与原理
1. 观点陈述：用作者的原话或精准概括
2. 支撑论据：支持这个观点的证据/逻辑
3. 前提假设：这个观点成立的条件
4. 适用边界：什么情况下适用/不适用

### 🔧 第三部分：应用层

#### 3.1 方法论与工具
- 方法/工具名称
- 使用步骤：具体的操作流程
- 注意事项：使用时的关键要点
- 效果预期：使用后能达到什么效果

#### 3.2 案例分析与实践路径
- 书中案例精选
- 行动转化清单：
  - 📌 立即可做
  - 📅 短期项目
  - 🎯 长期修炼

### 🤔 第四部分：批判与提升层

#### 4.1 批判性分析
- 局限性识别
- 争议点讨论

#### 4.2 知识内化测试
- 理解层（记忆）
- 应用层（运用）
- 创新层（迁移）

## 学术论文专用模板

### 论文信息
- 标题/作者/期刊/年份/DOI

### 结构化摘要
- 背景/目标
- 方法
- 结果
- 结论

### 深度解析
1. 研究背景与核心问题
2. 文献综述与研究缺口
3. 研究设计与方法
4. 结果与发现
5. 讨论与贡献

## 输出要求

1. 使用清晰的标题层级
2. 概念体系必须使用树状结构展示
3. 列表和表格相结合
4. 每个部分都要有具体例子
5. 保持专业性与可读性平衡
