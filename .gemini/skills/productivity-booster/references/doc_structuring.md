# 文档结构化处理提示词

## 核心使命

将非结构化或半结构化的文档内容转换为清晰、层次分明、易于阅读和检索的结构化格式。

## 适用场景

| 场景 | 输入特征 | 输出格式 |
|------|---------|---------|
| 会议纪要整理 | 杂乱的会议记录 | 结构化会议纪要 |
| 访谈记录结构化 | 对话式原始记录 | 主题归类报告 |
| 报告文档重组 | 格式混乱的报告 | 标准化报告 |
| 笔记内容梳理 | 碎片化笔记 | 系统性知识库 |
| 长文档拆解 | 冗长文档 | 模块化章节 |

## 结构化原则

### 1. 层级清晰原则
- 建立明确的标题层级（H1→H2→H3→H4）
- 从总体到细节逐层递进
- 同级内容并列呈现
- 避免超过4级标题

### 2. 逻辑连贯原则
- 内容按逻辑顺序排列
- 相关内容归类聚合
- 保持论述的完整性
- 添加过渡语句连接

### 3. 信息精炼原则
- 提取核心信息
- 去除冗余表述
- 保留关键细节
- 突出重点内容

### 4. 格式统一原则
- 统一标点符号使用
- 统一列表格式
- 统一表格样式
- 统一引用格式

## 处理流程

### Step 1：内容分析（20%时间）

**目标**：理解文档全貌

**操作**：
1. 通读全文，理解核心主旨
2. 识别文档类型（报告/纪要/笔记/其他）
3. 标记关键段落和重要信息
4. 识别现有的结构（如有）

**输出**：内容分析清单
```markdown
- 文档类型：[类型]
- 核心主题：[主题]
- 关键段落：[段落位置]
- 现有结构：[有/无]
```

### Step 2：结构规划（20%时间）

**目标**：设计目标结构

**操作**：
1. 根据文档类型选择标准模板
2. 设计标题层级框架
3. 规划内容分布位置
4. 确定信息归类方式

**输出**：结构大纲
```markdown
# 一级框架
## 二级框架1
### 三级内容
## 二级框架2
```

### Step 3：内容重组（40%时间）

**目标**：按结构填充内容

**操作**：
1. 按框架归类原文内容
2. 调整段落顺序
3. 补充过渡连接语句
4. 删除重复冗余内容

**技巧**：
- 相似内容合并
- 对立内容对比呈现
- 重要内容前置
- 细节内容后置

### Step 4：格式输出（20%时间）

**目标**：规范化输出

**操作**：
1. 应用Markdown格式规范
2. 统一文档风格
3. 检查结构完整性
4. 验证链接和引用

## 常见文档结构模板

### 报告类文档
```markdown
# 报告标题

## 执行摘要
[核心结论，1-2段]

## 一、背景介绍
[问题背景与分析目的]

## 二、分析过程
### 2.1 维度一
[具体内容]
### 2.2 维度二
[具体内容]

## 三、核心发现
1. [发现1]
2. [发现2]
3. [发现3]

## 四、结论与建议
### 4.1 结论
[总结要点]
### 4.2 建议
[行动建议]

## 附录
[补充资料]
```

```markdown
|------|------|

- **讨论要点**：
  1. [要点1]
  2. [要点2]
- **决议**：[决定事项]
- **负责人**：[姓名]
- **完成时间**：YYYY-MM-DD

### 议题二：[标题]
[同上结构]

## 待办事项汇总

| 序号 | 事项 | 负责人 | 截止日期 | 状态 |
|------|------|--------|---------|------|
| 1 | [事项] | [姓名] | YYYY-MM-DD | 待完成 |
| 2 | ... | ... | ... | ... |

## 下次会议
- **时间**：YYYY-MM-DD HH:MM
- **预计议题**：
  1. [议题1]
  2. [议题2]
```

## 特殊内容处理

### 表格数据
1. 识别数据的行列关系
2. 确定表头和数据区域
3. 使用Markdown表格语法
4. 对齐列宽以提升可读性

### 列表内容
1. 区分有序列表（步骤/优先级）和无序列表（并列项）
2. 统一列表符号（-或*）
3. 保持正确的缩进层级
4. 避免超过3层嵌套

### 引用内容
1. 使用 `>` 标记引用
2. 标注引用来源
3. 保持原意不篡改
4. 长引用可分段

### 代码/技术内容
1. 使用代码块包裹
2. 标注语言类型
3. 添加必要注释
4. 保持缩进规范

## 质量检查清单

在交付前验证：

- [ ] 结构完整：覆盖原文全部核心内容
- [ ] 层级分明：标题层级使用合理（≤4级）
- [ ] 逻辑清晰：内容排列有序，逻辑通顺
- [ ] 格式规范：符合Markdown标准
- [ ] 易于阅读：便于快速浏览和理解
- [ ] 无遗漏：重要信息未丢失
- [ ] 无重复：冗余内容已删除
