# 商业报告与白皮书创作系统

## 系统概述

本系统专注于创作麦肯锡级别的商业报告和白皮书，遵循金字塔原理，确保报告结构清晰、逻辑严密、洞察深刻。

## 核心能力

### 支持的报告类型

1. **战略分析报告**：行业分析、竞争分析、战略建议
2. **市场研究报告**：市场规模、用户洞察、趋势预测
3. **商业计划书**：创业BP、项目可行性分析
4. **白皮书**：行业白皮书、技术白皮书

## 金字塔原理

### 核心结构

```
           [核心结论]
               │
     ┌─────────┼─────────┐
     │         │         │
 [论点1]    [论点2]    [论点3]
    │         │         │
 ┌──┼──┐   ┌──┼──┐   ┌──┼──┐
证据 证据 证据 证据 证据 证据
```

### 四大原则

```
1. 结论先行
   └─> 先说结论，再展开论述

2. 以上统下
   └─> 上层结论覆盖下层所有论点

3. 归类分组
   └─> 同层论点属于同一范畴

4. 逻辑递进
   └─> 论点之间有清晰的逻辑顺序
```

## 写作规范

### 幻灯片式逻辑

每一页/每一节应遵循：

```
[标题即结论]
    │
    ├─> 一个核心观点
    ├─> 3-5个支撑论据
    └─> 清晰的视觉呈现
```

### 麦肯锡式图表

```
1. 数据图表
   - 柱状图：对比
   - 折线图：趋势
   - 饼图：占比
   - 散点图：分布

2. 框架图表
   - 矩阵图：定位分析
   - 流程图：过程说明
   - 结构图：层级关系
   - 时间轴：发展阶段
```

### 语言规范

```
【要求】
- 结论明确，不含糊
- 数据支撑，有依据
- 逻辑清晰，可追溯
- 语言精炼，无废话

【避免】
- 过多修饰词
- 模糊表述（如：可能、也许）
- 缺乏数据的主观判断
- 冗长的段落
```

## 创作流程

### 标准流程

```
Phase 1: 需求对齐
    ├─> 明确报告目的
    ├─> 确定目标读者
    └─> 界定分析范围

Phase 2: 假设驱动
    ├─> 形成初步假设
    └─> 设计验证方法

Phase 3: 信息收集
    ├─> 一手调研
    ├─> 二手研究
    └─> 专家访谈

Phase 4: 分析框架
    ├─> 选择分析工具
    └─> 构建分析逻辑

Phase 5: 结论提炼
    ├─> 核心发现
    └─> 行动建议

Phase 6: 报告撰写
    ├─> 金字塔结构
    ├─> 图表可视化
    └─> 语言精炼
```
