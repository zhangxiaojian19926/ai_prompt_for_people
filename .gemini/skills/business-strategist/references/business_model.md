### 九模块详解

#### 1. 客户细分 (Customer Segments)

**核心问题**：我们在为谁创造价值？

**常见细分方式**：
- 大众市场：面向普遍用户
- 利基市场：专注细分领域
- 多边平台：服务多方用户群

**输出模板**：
```markdown
## 客户细分
### 主要客户群
- 用户画像：[年龄/职业/收入等]
- 核心需求：[最重要的需求]
- 痛点问题：[最困扰的问题]
### 次要客户群（如有）
...
```

#### 2. 价值主张 (Value Propositions)

**核心问题**：我们为客户提供什么独特价值？

**价值类型**：
- 新颖性：创新解决方案
- 性能：更好的产品表现
- 定制化：满足个性需求
- 便利性：简化使用流程
- 价格：更有竞争力的定价
- 风险降低：减少不确定性
- 品牌/地位：提升身份认同

**输出模板**：
```markdown
## 价值主张
### 核心价值
- 一句话描述：[解决什么问题]
- 10倍优势：[比竞品好在哪]
### 价值证据
- [证据1]
- [证据2]
```

#### 3. 渠道通路 (Channels)

**核心问题**：如何触达和服务客户？

**渠道阶段**：
1. 认知：如何让客户知道我们
2. 评估：如何帮助客户评估价值
3. 购买：如何让客户购买
4. 交付：如何交付产品/服务
5. 售后：如何提供售后支持

#### 4. 客户关系 (Customer Relationships)

**核心问题**：与客户建立什么类型的关系？

**关系类型**：
- 个人服务：一对一服务
- 自助服务：客户自行操作
- 社区：用户社区运营
- 共同创造：与用户共创产品

#### 5. 收入来源 (Revenue Streams)

**核心问题**：客户愿意为什么付费？

**收入模式**：
```
1. 产品销售：卖产品
2. 使用费：按使用量收费
3. 订阅费：周期性付费
4. 租赁：临时使用权
5. 授权：知识产权许可
6. 佣金：交易抽成
7. 广告：曝光付费
8. Freemium：免费+增值
```

#### 6. 核心资源 (Key Resources)

**核心问题**：实现价值主张需要什么资源？

**资源类型**：
- 实物资源：设备、场地
- 知识资源：专利、技术
- 人力资源：人才、团队
- 财务资源：资金、信用

#### 7. 关键活动 (Key Activities)

**核心问题**：需要做什么才能运转？

**活动类型**：
- 生产：制造产品
- 解决方案：提供服务
- 平台/网络：运营平台

#### 8. 关键合作伙伴 (Key Partners)

**核心问题**：需要与谁合作？

**合作类型**：
- 战略联盟：非竞争对手合作
- 竞合：与竞争对手合作
- 供应商：关键供应链
- 资源共享：共享资源降成本

#### 9. 成本结构 (Cost Structure)

**核心问题**：运营需要什么成本？

**成本类型**：
- 固定成本：不随产量变化
- 可变成本：随产量变化
- 规模经济：量大降成本
- 范围经济：多元化降成本

## 盈利模式库

### 常见盈利模式

```
1. 交易型
   └─> 一次性购买
   
2. 订阅型
   └─> 周期性付费
   
3. 广告型
   └─> 流量变现
   
4. 佣金型
   └─> 交易抽成
   
5. Freemium
   └─> 免费吸引+付费增值
   
6. 剃刀模式
   └─> 低价硬件+高利润耗材
   
7. 平台型
   └─> 连接双边/多边市场
   
8. 数据型
   └─> 数据产品/服务
```

## 商业模式测试

### 关键假设验证

```
1. 客户假设
   └─> 目标客户真的存在吗？
   └─> 他们真的有这个需求吗？
   
2. 价值假设
   └─> 他们愿意为此付费吗？
   └─> 付费意愿有多高？
   
3. 渠道假设
   └─> 能有效触达他们吗？
   └─> 获客成本是多少？
   
4. 经济假设
   └─> 单位经济模型成立吗？
   └─> LTV > CAC吗？
```
