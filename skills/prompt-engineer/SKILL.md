## 核心框架

### PARE框架（工业级标准）
- **P**ersona：角色定义（身份、能力、经验）
- **A**ction：任务规范（目标、流程、决策）
- **R**estriction：约束条件（必须、禁止、质量）
- **E**xpectation：输出期望（格式、标准、示例）

### Agent提示词模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **ReAct** | 思考-行动-观察循环 | 工具调用、多步推理 |
| **CoT** | 链式思考 | 复杂推理、数学问题 |
| **ToT** | 思维树 | 探索性问题、决策 |
| **Self-Ask** | 自问自答分解 | 多跳问答 |
| **RAG** | 检索增强生成 | 知识库问答 |

### 多模态提示词结构

```markdown
## 图像分析提示词

### 视觉描述
[描述图像中需要关注的元素]

### 分析任务
[具体的分析目标]

### 输出格式
[期望的输出结构]

### 示例
[输入图像] → [期望输出]
```

## 工作流程

### 第一步：识别提示词类型

| 需求信号 | 类型 | 处理方式 |
|---------|------|---------|
| 涉及图像/视频分析 | 多模态 | 加载 multimodal_prompt.md |

### 第二步：加载参考文档与工具

1. 根据类型加载对应的参考文档
2. 如需Python脚本辅助，提供使用说明
3. 应用对应的设计模式

### 第三步：设计与生成

确保输出满足：
- ✅ 结构完整（包含所有必需模块）
- ✅ 内容具体（无空洞占位符）
- ✅ 可执行性（有明确操作指令）
- ✅ 可验证性（有质量标准）

### 第四步：评估与优化

使用评估工具验证质量并迭代优化。

## Python 工具脚本

### 脚本使用说明

```bash
# 生成图像分析提示词
python scripts/image_prompt.py --task "分析产品图" --output prompt.md

# 构建Agent提示词
python scripts/agent_builder.py --mode react --tools "search,calculate" --output agent.md

# 分割长上下文
python scripts/context_splitter.py --input long_doc.md --max-tokens 4000 --output chunks/

# 评估提示词质量
python scripts/evaluate_prompt.py --input prompt.md --output report.md
```

## 约束条件

1. **工业级质量**：生成的提示词必须达到生产环境可用标准
2. **结构完整性**：严格遵循框架，不得省略核心模块
3. **内容实质性**：禁止空洞框架和"TODO"占位符
4. **可验证性**：必须包含质量标准和检查点
5. **自举能力**：本技能可用于优化自身
6. **模态适配**：多模态提示词需明确输入输出模态
7. **Agent安全**：Agent提示词需包含安全边界

## 常见陷阱

- ❌ **模态混淆**：多模态提示词未区分模态
- ❌ **工具缺失**：Agent提示词未定义工具
- ❌ **上下文丢失**：分块策略导致关键信息丢失
- ❌ **只有框架**：没有实质内容
- ❌ **缺少示例**：无法理解期望输出
- ❌ **无安全边界**：Agent可执行危险操作
