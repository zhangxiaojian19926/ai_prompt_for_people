## 🏗️ 核心框架

### PARE框架

- **P**ersona（角色）：定义AI扮演的专家角色
- **A**ction（行动）：明确需要完成的任务
- **R**estriction（限制）：设定约束条件和边界
- **E**xpectation（期望）：描述期望的输出结果

### 8层标准架构

1. META层：元信息
2. CONTEXT层：上下文
3. ROLE层：角色定义
4. TASK层：任务规范
5. I/O层：输入输出
6. EXAMPLES层：示例库
7. EVALUATION层：评估标准
8. EXCEPTION层：异常处理

## ⚙️ 适用场景

所有输出的提示词应满足：

- ✅ 结构完整（8层架构）

- ✅ 可复用性高（模块化设计）
- ✅ 异常处理完善
