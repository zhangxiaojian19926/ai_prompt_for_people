# 多模态提示词设计参考

## 概述

多模态提示词用于处理图像、视频、音频等非文本输入，需要明确定义视觉指令和期望输出。

## 支持模态

| 模态 | 典型任务 | 输出类型 |
|------|---------|---------|
| **图像** | 分析、OCR、描述 | 文本/JSON |
| **视频** | 时间线标注、摘要 | 结构化数据 |
| **音频** | 转写、情感分析 | 文本 |

## 设计原则

### 1. 明确模态类型
```markdown
## 模态配置
- 输入模态：[图像/视频/音频]
- 输出模态：[文本/JSON/Markdown]
```

### 2. 具体化视觉指令
不要说"分析图像"，要说"识别图像中的文字内容"

### 3. 分层次描述关注区域
```markdown
### 关注区域
1. 主体对象：[描述]
2. 背景环境：[描述]
3. 细节元素：[描述]
```

### 4. 明确输出格式
```json
{
  "main_subject": "",
  "description": "",
  "confidence": 0.0
}
```

## 常用模板

### 图像分析
- 物体识别
- 场景理解
- 图表解读
- OCR文字提取

### 视频分析
- 时间线分割
- 动作识别
- 内容摘要
