# 结构复用生成器

## 系统概述

本系统能够基于已有的结构模板，快速生成符合相同格式但内容不同的新提示词。这是一种高效的提示词生成方法，特别适合批量创建同类型的提示词。

## 核心概念

### 什么是结构复用？

将优秀提示词的**结构**提取出来，保持框架不变，只替换具体的内容，快速生成新的提示词。

**示例**：
```
模板结构：产品介绍提示词
- 标题
- 产品定位
- 核心功能（3个）
- 使用场景
- 优势对比

复用：只需替换具体产品名称和功能描述，结构保持不变
```

## 使用场景

### 场景1：批量创建同类提示词

当你需要为多个相似对象创建提示词时：
- 为不同产品创建介绍提示词
- 为不同角色创建Role提示词
- 为不同领域创建分析提示词

### 场景2：保持团队一致性

团队协作时，统一提示词格式：
- 使用标准模板
- 确保质量一致  
- 提高可维护性

### 场景3：快速原型

快速验证想法：
- 套用成熟模板
- 节省设计时间
- 专注内容填充

## 工作原理

### 输入

```
{
  "结构模板": "[已有的优秀提示词]",
  "新主题/内容": "[要生成的新内容]"
}
```

### 处理流程

```
Step 1: 分析模板结构
    └─> 识别模板的层级、模块、格式

Step 2: 提取结构骨架
    └─> 去除具体内容，保留框架

Step 3: 语义位置映射
    └─> 理解每个位置的语义功能

Step 4: 填充新内容
    └─> 根据新主题生成对应内容

Step 5: 格式对齐
    └─> 确保格式与模板完全一致
```

### 输出

```
输出必须：
- 包裹在代码块中
- 严格复用结构模板的结构
- 内容全部围绕新主题/内容
- 每一段/每一行的"语义位置"都对应映射
```

## 质量保证

### 检查清单

- [ ] 结构层级是否完全一致？
- [ ] 模块数量是否匹配？
- [ ] 格式（标题级别、编号）是否对齐？
- [ ] 内容是否完全围绕新主题？
- [ ] 语义位置是否准确映射？

### 常见问题

**问题1**：生成的内容太短
**解决**：明确要求"保持与模板相似的内容量"

**问题2**：结构发生变化
**解决**：强调"严格保持结构不变"

**问题3**：内容不够具体
**解决**：提供更详细的新主题描述
