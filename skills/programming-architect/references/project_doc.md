# 项目上下文文档生成

## 核心使命

基于当前已知信息，生成一份完整、结构化、可迁移、可长期维护的项目上下文文档，作为项目的"记忆中枢"。

## 文档价值

| 场景 | 价值 |
|------|------|
| 新成员入职 | 快速了解项目全貌 |
| AI对话接续 | 恢复上下文继续讨论 |
| 项目交接 | 完整知识传递 |
| 复盘回顾 | 追踪决策演变 |

## 执行流程

### Step 1：信息收集

从对话/文档/代码中提取以下信息：
- 项目名称和背景
- 目标和需要解决的问题
- 已确定的技术方案
- 当前进展和待解决问题

### Step 2：结构化整理

将信息填入标准化模板的各个模块

### Step 3：验证完整性

检查所有字段是否有值或明确标注"暂无信息"

### Step 4：输出文档

以Markdown格式输出完整文档

## 重要规则

1. **信息完整性**：若某字段在当前对话中未明确出现或无法合理推断，必须保留该字段，填写为"暂无信息"
2. **不虚构事实**：不得自行编造未确认的信息
3. **结构稳定**：不得省略任何字段，保持模板结构一致
4. **可迁移性**：文档可直接粘贴用于新对话恢复上下文

## 质量检查清单

- [ ] 所有必填字段是否都有内容或标注"暂无信息"？
