# 🧠 知识工程与学习专家 (knowledge-engineer)

> 系统性思维分析、概念解释、知识结构化的专业技能。

## 📋 技能概述

本技能整合48种系统性思维工具和12维度概念分析框架，帮助用户深入理解复杂概念、构建知识体系、进行深度分析。

## 💡 使用示例

### 示例1：深度分析

```
请用系统性思维工具对以下问题进行深度分析：

[你的问题/想法/文本]

要求：
- 运用至少5种思维模型
- 明确核心问题和本质逻辑
- 识别潜在陷阱
- 给出策略建议
```

### 示例2：概念解释

```
请用全维度方法解释"区块链"

要求：
- 从通俗定义开始
- 使用生活化比喻
- 深入多个分析维度
- 澄清常见误解
```

### 示例3：知识结构化

```
请帮我构建"机器学习"的知识体系

要求：
- 核心概念层级
- 概念之间的关系
- 学习路径建议
```

## 🏗️ 核心工具

### 48种思维模型（分层）

**基础逻辑工具**
- 第一性原理
- 系统化思维
- 批判性思维
- 元思维/元反思

**结构分析工具**
- 冰山模型
- 金字塔原理
- MECE原则
- 五因追问法

**决策分析工具**
- 决策树模型
- 博弈论模型
- 情景规划
- 风险矩阵

**执行优化工具**
- 马斯克五步工作法
- PDCA闭环
- 复盘模型

### 12维度概念分析

1. 系统论视角
2. 第一性原理
3. 二阶思维
4. 必要性与充分性
5. 逻辑链分析
6. 奥卡姆剃刀
7. 内涵与外延
8. 输入-处理-输出模型
9. 黄金圈法则
10. 是什么-为什么-怎么用
11. 历史演化视角
12. 跨学科关联

## ⚙️ 适用场景

- 复杂问题深度分析
- 概念学习与理解
- 知识体系构建
- 决策思路梳理
- 学习方法提升

## 📊 输出标准

所有输出应满足：

- ✅ 多维度分析（不遗漏视角）
- ✅ 逻辑严谨（推理可追溯）
- ✅ 通俗易懂（易于理解）
- ✅ 可操作性（有实践指导）
