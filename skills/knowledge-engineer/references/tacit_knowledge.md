# 隐性知识挖掘提示词

## 核心使命

识别并提取内容中未明确表达但支撑其逻辑的隐性知识、默认假设、背景规律和专家经验。

## 隐性知识的定义

隐性知识是指那些：
- 未被言明但被普遍默认的特征
- 支撑表层逻辑的深层假设
- 专家在实践中积累但难以言传的经验
- 特定语境下的潜规则和惯例

## 挖掘框架

### 第一层：假设识别

#### 1.1 显式假设
- 作者明确陈述的前提条件
- 文本中直接表达的假定

#### 1.2 隐式假设
- 必须成立但未被陈述的条件
- 读者被默认应该知道的背景

#### 1.3 元假设
- 关于思考方式本身的假设
- 关于知识形成过程的假设

### 第二层：规律提取

#### 2.1 表层规律
- 直接可观察到的模式
- 明确的因果关系

#### 2.2 深层规律
- 现象背后的根本法则
- 跨情境一致的原则

#### 2.3 反直觉规律
- 与常识相悖但实际有效的规则
- 专家知道但新手容易忽略的要点

### 第三层：经验提取

#### 3.1 实践经验
- 行业内不成文的经验规则
- 从失败中总结的教训
- 实践者的直觉和感悟

#### 3.2 情境化知识
- 特定场景下的应用技巧
- 因地制宜的变通方法
- 文化背景对理解的影响

#### 3.3 专家洞察
- 资深实践者的独特见解
- 非正式的传承知识
- 难以言传但极其重要的诀窍

## 分析模板

### 输入分析

```
你是一个善于挖掘隐性知识的AI助手。
你的任务是分析给定的内容，识别并提取其中：

1. 隐性假设
   - 这段内容成立需要哪些未被明说的前提？
   - 作者默认读者知道什么？

2. 深层规律
   - 表面现象背后的根本法则是什么？
   - 有哪些跨情境一致的原则？

3. 专家经验
   - 行内人知道但新手不知道的关键点是什么？
   - 有哪些反直觉但实际有效的做法？

4. 潜在盲点
   - 作者可能忽略了什么？
   - 在什么情境下这些结论可能失效？
```

### 输出格式

```markdown
## 隐性知识分析报告

### 一、识别的隐性假设
1. [假设1] - 论证：为什么这是必要假设
2. [假设2] - 论证：...

### 二、提取的深层规律
1. [规律1] - 应用场景
2. [规律2] - 应用场景

### 三、专家经验洞察
1. [经验1] - 如何应用
2. [经验2] - 如何应用

### 四、潜在盲点警示
1. [盲点1] - 可能的影响
2. [盲点2] - 可能的影响

### 五、知识迁移建议
- 这些隐性知识在其他领域的应用...
```

## 质量标准

1. 挖掘的隐性知识必须有逻辑支撑
2. 避免过度解读或臆测
3. 区分"可能的假设"和"必然的假设"
4. 提供隐性知识的验证方法
5. 考虑文化和语境因素

## 应用场景

- 阅读专业书籍时挖掘作者未明说的经验
- 分析案例时提取普适性规律
- 学习新领域时识别入门者常忽略的要点
- 进行知识迁移时找到底层共性
