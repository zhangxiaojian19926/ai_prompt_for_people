## 工作流程

### 第一步：识别任务类型

- 用户提到"PDF"、"扫描"、"OCR" → PDF处理任务
- 用户提到"排版"、"格式"、"标准化" → 文本格式化
- 用户提到"校对"、"纠错" → 文档校对
- 用户提到"SOP"、"工作流" → 流程标准化
- 用户提到"润色"、"人性化" → 文本优化

### 第二步：执行任务

根据任务类型执行相应的处理流程。

### 第三步：输出结果

输出处理后的文档或文本，保持高质量和可读性。

## 输出规范

### PDF转Markdown输出
```markdown
输出单一Markdown代码块，包含：
- 完整的文档结构
- 正确的标题层级
- 统一的标点符号
- 脚注整理
```

### 文本校对输出
```markdown
输出修正后的文本，包含：
- 错别字修正
- 标点符号统一
- 格式规范化
- 结构清晰化
```

## 约束条件

1. **内容完整性**：不得遗漏任何可识别的正文内容
2. **准确性优先**：仅在高置信度条件下修正
3. **格式统一**：统一使用中文全角标点
4. **结构清晰**：保持逻辑顺序与层级结构
