## 工作流程

### 第一步：识别任务类型

根据用户输入信号识别任务：

| 输入信号 | 任务类型 | 处理方式 | 工具支持 |
|---------|---------|---------|---------|
| 长文章、报告 | 智能摘要 | 多级摘要生成 | `summarize.py` |
| 外语文档、翻译需求 | 智能翻译 | 双语对照输出 | `translate.py` |
| 会议记录、讨论内容 | 会议纪要 | 行动项提取 | `extract_actions.py` |
| CSV/Excel/表格数据 | 表格处理 | 格式转换清洗 | `table_converter.py` |
| 多个文件、批量任务 | 批量处理 | 统一处理输出 | `batch_process.py` |
| 模板应用、快速生成 | 模板系统 | 变量替换生成 | `apply_template.py` |
| PDF/扫描件 | PDF转换 | OCR+Markdown | - |
| 格式混乱、排版问题 | 排版优化 | 结构标准化 | - |
| 错别字、语法问题 | 校对纠错 | 错误修正 | - |

### 第二步：加载参考文档与工具

1. 根据任务类型加载对应的参考文档
2. 如需Python脚本辅助，提供脚本使用说明
3. 获取任务专属的处理规范

### 第三步：执行处理任务

按照规范执行任务：
1. 保持内容完整性
2. 应用格式规范
3. 使用工具脚本（如适用）
4. 进行质量自检

### 第四步：输出与验收

交付处理结果：
1. 验证输出质量
2. 确认格式正确性
3. 提供处理说明

## Python 工具脚本

### 脚本使用说明

所有脚本位于 `scripts/` 目录，可直接运行：

```bash
# 智能摘要
python scripts/summarize.py --input document.md --level brief
python scripts/summarize.py --input document.md --level detailed --keywords

# 智能翻译
python scripts/translate.py --input doc.md --source en --target zh

# 行动项提取
python scripts/extract_actions.py --input meeting.md --output actions.md

# 表格转换
python scripts/table_converter.py --input data.csv --output table.md
python scripts/table_converter.py --input data.xlsx --sheet Sheet1

# 批量处理
python scripts/batch_process.py --input-dir ./docs --task proofread --output-dir ./output

# 应用模板
python scripts/apply_template.py --template report.tpl --vars config.json --output output.md
```

## 约束条件

1. **内容完整性**：不得遗漏任何可识别的正文内容
2. **准确性优先**：仅在高置信度条件下修正
3. **格式统一**：统一使用中文全角标点
4. **结构清晰**：保持逻辑顺序与层级结构
5. **保持原意**：翻译/润色不改变内容原意
6. **可执行性**：SOP步骤必须具体可操作
7. **标准化**：遵循Markdown规范
8. **透明处理**：重大修改需说明理由

## 常见陷阱

避免以下问题：

- ❌ **摘要过长**：摘要应该精简，不是重写
- ❌ **翻译生硬**：需要本地化处理，非逐字翻译
- ❌ **遗漏行动项**：会议纪要必须提取所有待办
- ❌ **数据丢失**：表格转换不能丢失数据
- ❌ **格式不一**：批量处理输出格式必须统一
- ❌ **模板僵化**：模板仅作参考，需灵活调整
