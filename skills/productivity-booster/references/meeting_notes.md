# 会议纪要增强参考文档

## 概述

会议纪要增强功能用于从会议记录中自动提取行动项、决议和关键信息。

## 提取内容

| 类型 | 说明 | 关键词 |
|------|------|--------|
| **行动项** | 待办任务 | 负责、跟进、完成、提交 |
| **决议** | 已达成的共识 | 决定、同意、确定、通过 |
| **责任人** | 任务负责人 | @姓名、负责人：XX |
| **截止日期** | 任务截止时间 | X月X日、本周、下周 |

## 行动项提取规则

### 关键词匹配
```
- "负责"、"跟进"、"完成"、"提交"
- "准备"、"确认"、"联系"、"安排"
- "需要"、"待办"、"TODO"、"Action"
```

### 责任人识别
```
模式1: "负责人：张三"
模式2: "@张三"
模式3: "由张三负责"
模式4: "张三跟进"
```

### 日期提取
```
精确日期: 2024-01-15, 1月15日
相对日期: 本周五、下周一、明天
默认: 一周后
```

## 输出格式

```markdown
## 会议纪要

### 会议信息
- 日期：2024-01-15
- 参会人：张三、李四、王五
- 主题：项目进度讨论

### 决议事项
1. ✅ 确定产品1.0版本于2月底发布
2. ✅ 同意增加2名开发资源

### 行动项
| 序号 | 任务 | 负责人 | 截止日期 | 状态 |
|------|------|--------|---------|------|
| 1 | 完成需求文档 | 张三 | 2024-01-20 | ⏳待完成 |
| 2 | 准备测试环境 | 李四 | 2024-01-22 | ⏳待完成 |

### 讨论要点
- 当前进度符合预期
- 需要注意第三方对接风险

### 下次会议
- 时间：下周一 14:00
- 议题：技术方案评审
```

## Python 脚本使用

```bash
# 基本提取
python scripts/extract_actions.py -i meeting.md

# 输出到文件
python scripts/extract_actions.py -i meeting.md -o actions.md

# 筛选特定责任人
python scripts/extract_actions.py -i meeting.md --assignee "张三"

# JSON格式输出
python scripts/extract_actions.py -i meeting.md -f json
```

## 质量标准

- ✅ 所有行动项完整提取
- ✅ 责任人明确分配
- ✅ 截止日期清晰
- ✅ 决议事项高亮
