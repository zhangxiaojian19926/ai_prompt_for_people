# 智能摘要参考文档

## 概述

智能摘要功能用于从长文本中自动提炼核心信息，支持多级摘要策略。

## 摘要级别

| 级别 | 说明 | 适用场景 |
|------|------|---------|
| **brief** | 一句话摘要（50字内） | 快速了解、标题生成 |
| **detailed** | 要点列表（3-5条） | 会议/报告回顾 |
| **structured** | 结构化摘要 | 正式文档、研究报告 |

## 工作流程

### 1. 文本预处理
- 分句：按句号、问号、感叹号切分
- 去噪：移除空行、重复内容
- 标准化：统一格式

### 2. 关键信息提取
- **主题识别**：提取核心主题
- **关键词**：高频词统计
- **重要句子**：按位置和长度筛选

### 3. 摘要生成策略

#### 一句话摘要 (brief)
```
策略：提取首句 + 核心关键词融合
长度：50字以内
```

#### 要点摘要 (detailed)
```
策略：TopN重要句子
数量：3-5条
格式：编号列表
```

#### 结构化摘要 (structured)
```
背景：文章背景说明
核心内容：主要论点/发现
结论：总结性内容
关键词：5个核心关键词
```

## 输出格式

```markdown
## 摘要报告

### 一句话摘要
[核心信息，50字以内]

### 关键要点
1. [要点1]
2. [要点2]
3. [要点3]

### 关键词
`关键词1` `关键词2` `关键词3`
```

## Python 脚本使用

```bash
# 简短摘要
python scripts/summarize.py -i document.md -l brief

# 详细要点
python scripts/summarize.py -i document.md -l detailed

# 结构化摘要（含关键词）
python scripts/summarize.py -i document.md -l structured --keywords -o summary.md
```

## 质量标准

- ✅ 摘要信息完整，无关键遗漏
- ✅ 语句通顺，可独立理解
- ✅ 长度符合级别要求
- ✅ 关键词准确反映主题
