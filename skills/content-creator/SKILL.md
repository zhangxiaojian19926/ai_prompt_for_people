## 工作流程

### 第一步：识别内容类型与平台

根据用户需求确定内容形式：

| 平台/形式 | 特点 | 核心要求 |
|----------|------|---------|
| 推特串文 | 10-20条，信息密集 | Hook + 逻辑递进 + CTA |
| 小红书 | 图文并茂，种草向 | 标题党 + emoji + 干货 |
| 微信公众号 | 深度长文，阅读体验 | 金句开头 + 结构清晰 |
| 朋友圈 | 简短有力，引发互动 | 情感共鸣 + 留白 |
| 营销落地页 | 转化导向 | 痛点 + 解决方案 + CTA |

### 第二步：明确内容要素

收集创作必需信息：

```markdown
## 创作brief

### 基本信息
- **目标平台**：[具体平台]
- **内容主题**：[核心话题]
- **目标受众**：[受众画像]

### 内容要求
- **核心信息**：[必须传达的内容]
- **期望语气**：[正式/轻松/专业/幽默]
- **字数要求**：[大致字数]
- **CTA目标**：[希望读者做什么]

### 参考素材
- [素材1]
- [素材2]
```

### 第三步：加载参考文档并创作

根据内容类型加载对应的创作框架：
1. 应用平台特定的格式规范
2. 使用验证有效的内容结构
3. 融入高互动技巧

### 第四步：优化与交付

完成创作后进行优化：
1. 检查标题/Hook吸引力
2. 验证内容逻辑通顺
3. 确认CTA清晰有力
4. 运行质量检查清单

## 约束条件

1. **平台适配**：符合目标平台的特性和限制
2. **吸引力优先**：使用钩子和情感触发点
3. **可操作性**：内容包含明确的价值和行动建议
4. **风格一致**：保持品牌/作者风格一致性
5. **信息准确**：数据和事实需有据可查
6. **原创为主**：避免直接复制他人内容
7. **读者视角**：从读者利益出发构建内容
8. **视觉友好**：合理使用格式增强可读性

## 质量检查清单

在交付前必须验证：

### 通用检查
- [ ] 标题/Hook是否足够吸引人？
- [ ] 核心信息是否清晰传达？
- [ ] 内容逻辑是否通顺？
- [ ] CTA是否清晰有力？
- [ ] 语气是否符合目标受众？

### 推特串文
- [ ] 总帖数是否在10-20条之间？
- [ ] 是否按[Hook → Meta → Body → Conclusion → CTA]结构？
- [ ] Emoji使用是否得当？
- [ ] 70-80%帖子是否有配图提示？

### 小红书笔记
- [ ] 标题是否包含数字和emoji？
- [ ] 是否有清晰的干货列表？
- [ ] 标签是否准确相关？
- [ ] 是否有互动引导？

### 长文创作
- [ ] 开头是否有吸引力？
- [ ] 结构是否清晰可预览？
- [ ] 是否有足够的案例/数据支撑？
- [ ] 结论是否有行动号召？

## 常见陷阱

避免以下问题：

- ❌ **开头平淡**：第一句没有吸引力
- ❌ **自说自话**：不考虑读者需求
- ❌ **信息过载**：一次传达太多内容
- ❌ **CTA模糊**：读者不知道下一步做什么
- ❌ **风格不匹配**：语气与平台或品牌不符
- ❌ **缺乏结构**：长文没有清晰的导航
