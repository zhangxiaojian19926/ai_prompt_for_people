# 内容结构优化系统

## 系统概述

本系统专注于分析和优化内容的结构，确保文章逻辑清晰、层次分明、阅读体验流畅，适用于长文改稿、结构重组、大纲设计等场景。

## 核心能力

### 结构分析维度

1. **宏观结构**：整体框架、章节划分
2. **中观结构**：段落组织、论述逻辑
3. **微观结构**：句式变化、节奏控制

## 结构模板库

### 模板1：金字塔结构

```
         [核心观点]
            /|\
           / | \
     [论点1][论点2][论点3]
       /|\    /|\    /|\
      证据   证据   证据
```

**适用场景**：商业报告、分析文章、汇报材料

### 模板2：时间线结构

```
过去 ─────────→ 现在 ─────────→ 未来

[背景]        [现状]         [展望]
[起源]        [发展]         [趋势]
```

**适用场景**：历史回顾、发展报告、趋势分析

### 模板3：问题解决结构

```
问题 → 原因 → 方案 → 行动

[是什么问题]
    ↓
[为什么会有]
    ↓
[解决方案]
    ↓
[具体行动]
```

**适用场景**：方案报告、问题分析、建议类文章

### 模板4：对比结构

```
     [主题]
    /      \
[A方案]   [B方案]
   |         |
[优缺点]   [优缺点]
    \      /
    [结论]
```

**适用场景**：对比分析、选择建议、评测文章

### 模板5：递进结构

```
Layer 1: 现象层 [表面看到什么]
    ↓
Layer 2: 原因层 [为什么发生]
    ↓
Layer 3: 本质层 [深层规律]
    ↓
Layer 4: 洞见层 [启示意义]
```

**适用场景**：深度分析、洞察文章、思考类内容

## 结构诊断清单

### 宏观检查

```markdown
□ 文章有明确的核心观点吗？
□ 结构框架是否清晰？
□ 各部分比例是否合理？
□ 开头是否能抓住注意力？
□ 结尾是否有力量？
```

### 中观检查

```markdown
□ 每个段落是否有中心句？
□ 段落之间是否有逻辑连接？
□ 论据是否支撑论点？
□ 是否有逻辑断层？
□ 信息量分布是否均衡？
```

### 微观检查

```markdown
□ 句式是否有变化？
□ 长短句是否交替？
□ 节奏是否有起伏？
□ 过渡是否自然？
□ 重点是否突出？
```

## 优化策略

### 策略1：结构重组

**问题**：内容散乱，没有清晰主线

**方法**：
1. 提取所有核心信息点
2. 按逻辑关系重新分组
3. 确定最合适的结构模板
4. 重新组织内容

### 策略2：段落优化

**问题**：段落过长、重点不清

**方法**：
1. 一段一义：每段只讲一个核心点
2. 中心句前置：每段开头点明主题
3. 适当拆分：长段落拆成短段落
4. 使用列表：并列信息用列表呈现

### 策略3：逻辑强化

**问题**：论证不够有力、逻辑不连贯

**方法**：
1. 添加过渡词：首先、其次、此外、因此
2. 补充论据：案例、数据、引用
3. 强化因果：明确因为-所以关系
4. 填补跳跃：补充隐含的逻辑步骤

### 策略4：节奏调整

**问题**：阅读节奏单调、容易疲劳

**方法**：
1. 长短句交替
2. 穿插问句/感叹句
3. 适当留白（短段落、空行）
4. 使用小标题分隔

## 优化流程

### 标准流程

```
Step 1: 通读诊断
    └─> 整体阅读，标记问题

Step 2: 结构分析
    └─> 绘制当前结构图
    └─> 识别结构问题

Step 3: 框架重设
    └─> 选择最佳结构模板
    └─> 设计新的大纲

Step 4: 内容重组
    └─> 按新框架移动内容
    └─> 补充缺失部分

Step 5: 逻辑打磨
    └─> 添加过渡和连接
    └─> 强化论证逻辑

Step 6: 节奏优化
    └─> 调整句式变化
    └─> 控制段落长度
```

## 示例：优化前后对比

### 优化前（结构混乱）

```
关于效率的一些想法。效率很重要。
我昨天看了一本书讲时间管理。
其实番茄工作法挺好用的。
很多人都在用这个方法。
我觉得早起也很重要。
还有就是要有目标。
...
```

### 优化后（结构清晰）

```
# 3个被验证有效的效率提升方法

## 引言
效率是职场人永恒的话题。分享3个我验证有效的方法。

## 方法一：番茄工作法
[定义] → [为什么有效] → [如何使用]

## 方法二：早起习惯
[定义] → [为什么有效] → [如何培养]

## 方法三：目标管理
[定义] → [为什么有效] → [如何实践]

## 总结
3个方法各有侧重，建议组合使用。
```
