# 风格模仿创作系统

## 系统概述

本系统能够分析特定作者或品牌的写作风格，并精确模仿该风格进行内容创作，确保输出内容在语气、结构、用词等方面与原风格高度一致。

## 核心能力

### 风格分析维度

#### 1. 语言特征分析

```
1.1 句式结构
    ├─> 句子长度偏好（长句/短句/混合）
    ├─> 句型偏好（陈述/疑问/感叹/祈使）
    └─> 段落结构（长段/短段/列表）

1.2 词汇特征
    ├─> 词汇难度（生僻词/日常词）
    ├─> 专业术语使用
    └─> 口语化程度

1.3 修辞手法
    ├─> 比喻/拟人/排比频率
    ├─> 引用/典故使用
    └─> 幽默/讽刺程度
```

#### 2. 叙事风格分析

```
2.1 叙述视角
    ├─> 第一/第二/第三人称
    └─> 主观/客观程度

2.2 情感基调
    ├─> 正面/负面/中性
    ├─> 热情/冷静
    └─> 轻松/严肃

2.3 逻辑结构
    ├─> 线性/非线性
    ├─> 归纳/演绎
    └─> 论述深度
```

#### 3. 独特标识

```
3.1 口头禅/标志性表达
3.2 标点符号使用习惯
3.3 Emoji使用风格
3.4 开头/结尾惯用方式
```

## 风格分析模板

### 分析报告格式

```markdown
# [作者/品牌名]风格分析报告

## 1. 语言DNA

### 句式特征
- 句子长度：[平均X字/短句为主/长句风格]
- 句型分布：[陈述X%/疑问X%/感叹X%]
- 段落风格：[长段落叙述/短段落节奏/列表化]

### 词汇画像
- 词汇层次：[学术型/日常型/网络流行语]
- 标志性用词：[列出3-5个代表性词汇]
- 禁用词汇：[该作者风格中不会出现的词]

### 修辞指纹
- 比喻使用：[频率高/适中/少]
- 幽默程度：[强/中/弱]
- 引用习惯：[经典/流行/少引用]

## 2. 叙事DNA

### 视角与口吻
- 人称：[第X人称为主]
- 主观程度：[高/中/低]
- 与读者距离：[亲近/专业/权威]

### 情感基调
- 总体色彩：[乐观/理性/批判]
- 情绪波动：[平稳/起伏/激烈]
- 态度倾向：[中立/鲜明立场]

### 结构模式
- 开篇方式：[钩子/背景/问题]
- 论述逻辑：[归纳/演绎/递进]
- 收尾习惯：[总结/金句/开放]

## 3. 独特标识

### 标志性元素
- 口头禅：[列出]
- 标点习惯：[如：喜欢用破折号/省略号]
- Emoji风格：[频繁/适度/不用]
- 段落节奏：[如：每段2-3句]

## 4. 模仿要点

### 必须保留
1. [最核心的风格特征1]
2. [最核心的风格特征2]
3. [最核心的风格特征3]

### 需要避免
1. [与该风格不符的特征1]
2. [与该风格不符的特征2]
```

## 模仿创作流程

### 标准流程

```
Step 1: 风格采样
    └─> 收集3-5篇目标作者/品牌的代表作品

Step 2: 风格分析
    └─> 输出风格分析报告

Step 3: 特征提取
    └─> 识别最关键的风格要素

Step 4: 模仿创作
    └─> 按新主题创作，保持风格一致

Step 5: 风格校验
    └─> 对照分析报告检查是否符合
```

## 快速使用

### 请求格式

```
请模仿以下文章的风格，创作关于[新主题]的内容：

---原文开始---
[粘贴原文]
---原文结束---

新内容主题：[描述]
新内容长度：[与原文相似/更长/更短]
```

### 高级请求

```
请先分析以下文章的写作风格，然后模仿该风格创作新内容：

---原文---
[粘贴原文]
---

请输出：
1. 风格分析报告
2. 基于该风格创作的新内容

新内容主题：[描述]
```

## 模仿示例

### 原文风格

```
15岁你在市图书馆最角落的架子发现了那本泛黄的《银河帝国》。
书脊已经破损，像是被无数人翻阅过又遗忘。
那天下午，你蜷缩在窗边的位置，阳光斜斜地照在"心理史学"那一页...
```

### 风格特征

- 第二人称叙述
- 细节描写丰富
- 场景感强烈
- 句子短小有节奏
- 带有怀旧/文艺气息

### 模仿输出

```
17岁那年夏天，你在老式唱片店的角落发现了那张落满灰尘的CD。
封面褪色严重，却依稀能看出是一位抱着吉他的少年。
店主正在打盹，阳光穿过百叶窗落在老式唱片机上...
```

## 注意事项

1. **法律合规**：模仿风格进行创作，不是抄袭内容
2. **保持原创**：内容本身必须原创，只模仿风格
3. **适度调整**：可根据新主题适当调整风格强度
4. **标注说明**：发表时建议注明"仿XX风格"
