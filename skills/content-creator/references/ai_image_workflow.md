# AI配图工作流参考

## 概述

AI配图工作流用于自动为文章生成配图提示词，支持多种设计风格。

## 工作流程

```
1. 提取文章关键场景
2. 选择配图风格
3. 生成提示词
4. 调用图像生成
5. 图文组合
```

## 配图类型

| 类型 | 用途 | 建议数量 |
|------|------|---------|
| **封面图** | 文章主视觉 | 1张 |
| **段落配图** | 内容插图 | 2-5张 |
| **信息图** | 数据展示 | 按需 |

## 风格选择

| 风格 | 特点 | 适用场景 |
|------|------|---------|
| `minimal` | 极简干净 | 商业/科技 |
| `illustration` | 插画风 | 生活/教育 |
| `realistic` | 写实 | 新闻/案例 |
| `3d` | 3D渲染 | 产品/概念 |
| `tech` | 科技感 | AI/技术 |

## 提示词模板

```
风格：[极简/插画/写实/3D]
场景：[具体场景描述]
主体：[主要元素]
色调：[色彩倾向]
构图：[居中/对称/三分法]
```

## Python脚本

```bash
python scripts/image_generator.py --input article.md --style minimal
python scripts/image_generator.py --list-styles
```

## 质量检查
- [ ] 风格是否统一？
- [ ] 提示词是否具体？
- [ ] 是否覆盖关键场景？
