# 视频脚本创作参考

## 概述

视频脚本用于规划视频内容，包括分镜、台词、画面描述等。

## 视频类型

| 类型 | 时长 | 平台 | 特点 |
|------|------|------|------|
| **短视频** | 15-60秒 | 抖音/快手 | 快节奏、强Hook |
| **中视频** | 3-10分钟 | B站/YouTube | 结构清晰 |
| **长视频** | 10分钟+ | YouTube | 深度内容 |

## 脚本结构

### 短视频（黄金3秒）
```
0-3秒：Hook（必须抓注意力）
3-45秒：主体内容
45-60秒：CTA
```

### 中视频
```
0-30秒：开场Hook
30秒-2分钟：问题引入
2-8分钟：主体内容（分3-4个部分）
8-9分钟：总结
9-10分钟：CTA
```

## 分镜表格式

| 时间 | 画面 | 台词 | 字幕 | 特效 |
|------|------|------|------|------|
| 0:00 | 特写镜头 | 开场白 | 大字幕 | 闪入 |

## Python脚本

```bash
python scripts/script_formatter.py --input draft.md --format short
python scripts/script_formatter.py --list-formats
```
