# 小红书与社交媒体文案创作系统

## 系统概述

本系统专注于创作适合各社交媒体平台的短文案，包括小红书种草文、朋友圈文案、微博动态等，确保内容符合平台特性并具有高传播力。

## 小红书创作规范

### 平台特性

- **用户群体**：年轻女性为主，追求品质生活
- **内容调性**：真实、种草、干货、有价值
- **核心关键词**：亲测、良心推荐、踩雷/避雷、YYDS

### 标题公式

```markdown
【数字法】5个让皮肤变好的习惯｜亲测有效
【对比法】用了3年护肤品 vs 用了3个月这个
【痛点法】皮肤暗沉？我终于找到原因了
【好奇法】最近为什么那么多人在用这个？
【权威法】皮肤科医生推荐的护肤顺序
```

### 正文结构

```markdown
【Hook】吸引停留 (1-2句)
最近被问到最多的就是：你皮肤怎么变好的？

【背景】引发共鸣 (1段)
之前我也是大油田+毛孔粗大...

【核心】干货内容 (2-3段)
后来找到了这几个方法：
1️⃣ ...
2️⃣ ...
3️⃣ ...

【总结】行动号召
姐妹们试试看！有用记得回来告诉我～

【标签】
#护肤 #变美秘籍 #护肤心得
```

### Emoji使用规范

```
✨ 强调亮点
💡 提示建议
❌ 避免/踩雷
✅ 推荐/正确
📍 地点标注
🔥 热门/推荐
💰 价格相关
⚠️ 注意事项
```

## 创作流程

### 标准流程

```
Step 1: 确定平台
    └─> 小红书/朋友圈/微博

Step 2: 明确目的
    └─> 种草/分享/互动/记录

Step 3: 提炼核心
    └─> 最想传达的1个核心信息

Step 4: 选择结构
    └─> 根据目的选择合适模板

Step 5: 填充内容
    └─> 真实、有价值、有个性

Step 6: 添加标签
    └─> 3-5个相关热门标签
```

## 注意事项

1. **真实性**：避免过度夸大，保持可信度
2. **原创性**：避免照搬模板，保持个性
3. **平台适配**：不同平台调性不同
4. **visual配合**：文案要配合图片/视频
5. **互动引导**：适当引导读者互动
