# 播客脚本创作参考

## 概述

播客脚本用于规划音频节目内容，包括开场、话题、对话和结束语。

## 播客类型

| 类型 | 人数 | 特点 | 时长 |
|------|------|------|------|
| **独白式** | 1人 | 主播讲述 | 10-30分钟 |
| **对谈式** | 2人 | 双人讨论 | 30-60分钟 |
| **访谈式** | 2+人 | 嘉宾采访 | 45-90分钟 |

## 脚本结构

### 通用结构
```
开场白 (2分钟)
├── 欢迎语
├── 主题介绍
└── 预告

主体内容 (80%时长)
├── 话题一
├── 话题二
└── 话题三

总结 (3分钟)
├── 要点回顾
├── 行动号召
└── 预告下期

结束语 (1分钟)
```

### 对话标记

```markdown
**A**: 这里是A说的话

**B**: 这里是B的回应
```

## Python脚本

```bash
python scripts/audio_script.py --topic "AI发展" --type solo --duration 20
python scripts/audio_script.py --list-types
```

- [ ] 时间分配是否合理？
