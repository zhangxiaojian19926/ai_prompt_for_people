# SEO优化参考

## 概述

SEO（搜索引擎优化）用于提升内容在搜索引擎中的排名和曝光。

## 核心要素

| 要素 | 重要性 | 优化建议 |
|------|--------|---------|
| **标题** | ⭐⭐⭐⭐⭐ | 含关键词、吸引点击 |
| **描述** | ⭐⭐⭐⭐ | 150字内、含CTA |
| **结构** | ⭐⭐⭐⭐ | H1-H6规范 |
| **关键词** | ⭐⭐⭐ | 密度0.5-2.5% |
| **链接** | ⭐⭐⭐ | 内链+外链 |
| **图片** | ⭐⭐ | Alt标签 |

## 标题优化

### 好的标题
- ✅ 包含目标关键词
- ✅ 50-60字符长度
- ✅ 有吸引力的描述

### 坏的标题
- ❌ 关键词堆砌
- ❌ 过长或过短
- ❌ 不知所云

## 关键词策略

### 密度计算
```
关键词密度 = (关键词出现次数 / 总词数) × 100%
理想范围：0.5% - 2.5%
```

### 分布位置
1. 标题（H1）
2. 第一段
3. 副标题（H2）
4. 正文自然分布
5. 结论

## Python脚本

```bash
python scripts/seo_checker.py --input article.md --keyword "目标关键词"
```

## 评分标准

| 分数 | 评级 | 说明 |
|------|------|------|
| 80+ | 优秀 | SEO表现出色 |
| 60-79 | 良好 | 小幅优化即可 |
| 40-59 | 待改进 | 需要优化 |
| <40 | 较差 | 需要大幅改进 |
