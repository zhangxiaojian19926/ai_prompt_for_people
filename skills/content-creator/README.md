# ✍️ 内容创作与文案专家 (content-creator)

> 社交媒体文案、长文创作、营销文案、风格模仿的专业技能。

## 📋 技能概述

本技能专注于各类内容创作任务，涵盖推特串文、小红书种草、朋友圈文案、长文通讯、营销文案等，确保内容符合平台特性并具有高传播力。

## 💡 使用示例

### 示例1：推特串文

```
请创作一个关于"AI如何改变教育"的推特串文

要求：
- 10-15条推文
- 吸引眼球的开篇
- 结尾有行动号召
```

### 示例2：小红书种草

```
请为以下产品创作小红书种草文：

产品：[产品名称]
核心卖点：[列出]
目标人群：年轻女性
风格：真诚分享
```

### 示例3：风格模仿

```
请模仿以下文章的风格，创作关于[新主题]的内容：

---原文---
[粘贴原文]
---

新内容主题：[描述]
```
