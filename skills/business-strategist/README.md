## 💡 使用示例

### 示例1：行业分析

```
请对"新能源汽车充电桩"行业进行麦肯锡级别的深度分析

分析目的：投资决策
重点关注：市场规模、竞争格局、发展趋势
时间维度：未来3-5年
```

### 示例2：SWOT分析

```
请为[公司名称]进行SWOT分析

目标：[决策目标]
```
