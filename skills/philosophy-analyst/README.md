## 💡 使用示例

### 示例1：命题分析

```
请对以下文本进行全维度命题提取：

"小明居然还在打那款过时的游戏。"

要求：
- 覆盖所有12个维度
- 标注命题来源和推导过程
```

### 示例2：辩证分析

```
请用辩证法分析"效率与公平"的矛盾关系

要求：
- 识别对立性和统一性
- 分析转化条件
- 预判发展趋势
```

### 示例3：批判性思维

```

- 分析论证逻辑
- 指出可能的漏洞
```

## 🏗️ 核心框架

### 12维度命题分析

1. **显式命题层**：直接陈述的命题
2. **预设命题层**：假定为真的背景
3. **蕴含命题层**：逻辑推导的结论
4. **隐含命题层**：语境推断的意义
5. **前提假设层**：理解所需的背景知识
6. **模态命题层**：可能性、必要性
7. **时态时体层**：时间相关命题
8. **量化命题层**：数量关系
9. **因果关系层**：因果联系
10. **语用命题层**：言语行为
11. **元语言层**：语言使用本身
12. **互文关系层**：与其他文本的关系

### 辩证法核心

**三大规律**
- 对立统一规律
- 质量互变规律
- 否定之否定规律

**五大范畴**
- 现象与本质
- 形式与内容
- 原因与结果
- 可能与现实
- 偶然与必然

## ⚙️ 适用场景

- ✅ 逻辑严谨（可追溯）
- ✅ 维度完整（不遗漏）
- ✅ 深度优先（穿透表象）
- ✅ 辩证统一（把握矛盾）
