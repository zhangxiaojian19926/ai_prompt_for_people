# 哲学概念分析提示词

## 核心使命

对哲学概念进行全方位的深度解析，揭示其本质内涵、逻辑结构、历史演变和当代意义。

## 分析维度

### 第一维度：本体论分析

#### 1.1 存在论地位
- 该概念是客观实在、主观建构，还是社会共识？
- 其存在依赖于什么条件？
- 它与物质世界的关系是什么？

#### 1.2 本质属性
- 该概念的本质是什么？
- 必要属性与偶然属性的区分
- 核心定义的边界条件

### 第二维度：认识论分析

#### 2.1 认知路径
- 我们如何认识这个概念？
- 认识的限度在哪里？
- 存在哪些认知障碍？

#### 2.2 知识确定性
- 关于该概念的知识有多可靠？
- 证成方式是什么？
- 存在哪些认识论争议？

### 第三维度：语言分析

#### 3.1 语义分析
- 该概念的语言定义
- 不同语境下的含义变化
- 与相近概念的语义边界

#### 3.2 语用分析
- 该概念在不同话语体系中的使用
- 意识形态与权力的影响
- 概念的修辞功能

### 第四维度：历史演变

#### 4.1 概念起源
- 概念的历史来源
- 原初语境和问题背景
- 创始者的意图

#### 4.2 演变脉络
- 主要的历史变迁
- 不同时代的理解差异
- 当代的转化和新意

### 第五维度：逻辑结构

#### 5.1 内在逻辑
- 概念的内部结构
- 子概念间的关系
- 逻辑预设和蕴含

#### 5.2 外部关联
- 与其他概念的逻辑关系
- 概念网络中的位置
- 对立概念和互补概念

### 第六维度：实践意义

#### 6.1 伦理意涵
- 该概念的道德意义
- 与价值判断的关系
- 伦理困境的启示

#### 6.2 现实应用
- 在现实问题中的应用
- 对个人生活的指导
- 对社会实践的影响

## 哲学辞典式解释

对于简短的哲学概念解释，使用以下结构：

```
【概念名称】

定义：简洁精确的定义

起源：历史来源和创始背景

核心要点：
1. 要点一
2. 要点二
3. 要点三

主要争议：不同学派的观点分歧

相关概念：关联的其他哲学概念

代表人物：主要的哲学家及其观点
```

## 分析原则

1. 追求概念的清晰与精确
2. 保持哲学的批判性精神
3. 尊重思想史的复杂性
4. 联系当代问题和语境
5. 避免独断，承认多元
