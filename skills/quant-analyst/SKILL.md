## 周期定位系统

> "理解你在周期中的位置，比预测周期更重要" —— Howard Marks

### 四维周期判断

| 周期 | 判断指标 | 位置选项 |
|------|---------|---------|
| **经济周期** | GDP、PMI、CPI | 复苏→繁荣→衰退→萧条 |
| **货币周期** | M2、利率、信贷 | 宽松→中性→紧缩 |
| **股市周期** | 估值分位、成交量 | 底部→上升→顶部→下降 |
| **行业周期** | 行业估值、景气度 | 导入→成长→成熟→衰退 |

```
              货币宽松                货币紧缩
```

## 回测系统

### 回测指标

| 指标 | 说明 | 优秀标准 |
|------|------|---------|
| **总收益率** | 策略总回报 | >基准 |
| **年化收益** | 年均复合增长 | >15% |
| **夏普比率** | 风险调整收益 | >1.0 |
| **最大回撤** | 最大亏损幅度 | <30% |
| **胜率** | 盈利交易占比 | >50% |
| **盈亏比** | 平均盈利/亏损 | >1.5 |

### 回测命令

```bash
python scripts/backtest.py \
  --symbol 159928 \
  --strategy value_invest \
  --start 2023-01-01 \
  --end 2025-12-31
```

## 智能仓位管理

### 动态仓位公式

```
仓位 = 基础仓位 × 估值系数 × 情绪系数 × 周期系数

估值系数:
  PE<20%分位 → 1.5
  PE 20-40%  → 1.2
  PE 40-60%  → 1.0
  PE 60-80%  → 0.7
  PE>80%分位 → 0.3

情绪系数:
  情绪<25    → 1.5 (恐惧时贪婪)
  情绪25-40  → 1.2
  情绪40-60  → 1.0
  情绪60-75  → 0.7
  情绪>75    → 0.3 (贪婪时恐惧)
```
