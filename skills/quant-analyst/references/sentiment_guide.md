# 情绪分析指南

> 系统化市场情绪分析方法论

## 核心理念

> "别人恐惧我贪婪，别人贪婪我恐惧" —— 巴菲特

情绪分析的目的是**量化市场情绪**，帮助投资者做出逆向投资决策。

---

## 情绪指标体系

### 1. 资金情绪指标

| 指标 | 数据源 | 恐惧信号 | 贪婪信号 | 权重 |
|------|--------|---------|---------|------|
| 融资余额变化 | 交易所 | 连续下降 | 连续上升 | 15% |
| 融券余额 | 交易所 | 大幅增加 | 大幅减少 | 10% |
| 北向资金 | 港交所 | 连续流出 | 连续流入 | 15% |
| ETF申购赎回 | 基金公司 | 净赎回 | 净申购 | 10% |

### 2. 交易情绪指标

| 指标 | 数据源 | 恐惧信号 | 贪婪信号 | 权重 |
|------|--------|---------|---------|------|
| 换手率 | 交易所 | 极低(<1%) | 极高(>5%) | 15% |
| 成交额/均值 | 计算 | <0.5 | >2.0 | 10% |
| 涨跌家数比 | 计算 | <0.3 | >3.0 | 15% |

### 3. 市场广度指标

| 指标 | 数据源 | 恐惧信号 | 贪婪信号 | 权重 |
|------|--------|---------|---------|------|
| 新高-新低 | 计算 | 新低多 | 新高多 | 10% |
| 涨停-跌停 | 交易所 | 跌停多 | 涨停多 | 5% |

## 情绪温度计

### 分区与操作建议

```
温度区间    状态        操作建议              巴菲特名言
─────────────────────────────────────────────────────────
0-15       极度恐惧    重仓买入              "别人恐惧我贪婪"
15-25      恐惧        积极买入              
25-40      悲观        逐步建仓              
40-60      中性        持有观望              等待更好机会
60-75      乐观        考虑减仓              
75-85      贪婪        逐步卖出              
85-100     极度贪婪    清仓离场              "别人贪婪我恐惧"
```

### 温度计算公式

```python
def calculate_sentiment_temperature():
    """
    情绪温度计算
    
    各指标归一化到0-100，然后加权平均
    """
    indicators = {
        "margin_change": normalize(融资余额5日变化率, -5%, 5%),
        "turnover_rate": normalize(平均换手率, 1%, 5%),
        "advance_decline": normalize(涨跌家数比, 0.2, 5),
        "volume_ratio": normalize(成交额/20日均值, 0.5, 2.0),
        "north_flow": normalize(北向5日净流入, -500亿, 500亿),
        "new_high_low": normalize(新高比例, 0, 1)
    }
    
    weights = {
        "margin_change": 0.15,
        "turnover_rate": 0.15,
        "advance_decline": 0.20,
        "volume_ratio": 0.15,
        "north_flow": 0.15,
        "new_high_low": 0.20
    }
    
    temperature = sum(indicators[k] * weights[k] for k in weights)
    return temperature
```

## 历史情绪极值案例

### 极度恐惧案例

| 时间 | 事件 | 情绪温度 | 后续走势 |
|------|------|---------|---------|
| 2008年10月 | 金融危机 | ~5 | 随后大涨 |
| 2015年9月 | 股灾末期 | ~10 | 反弹行情 |
| 2018年12月 | 贸易战恐慌 | ~12 | 2019年大涨 |
| 2020年3月 | 疫情冲击 | ~8 | V型反转 |
| 2024年2月 | 市场极度悲观 | ~10 | 强力反弹 |

**规律**：极度恐惧时往往是最佳买入时机

### 极度贪婪案例

| 时间 | 事件 | 情绪温度 | 后续走势 |
|------|------|---------|---------|
| 2007年10月 | 牛市顶点 | ~95 | 大熊市 |
| 2015年6月 | 杠杆牛顶点 | ~92 | 股灾 |
| 2021年2月 | 抱团股高峰 | ~85 | 大跌 |

**规律**：极度贪婪时往往是市场顶部

## 逆向操作策略

### 策略规则

```python
def sentiment_contrarian_strategy(temperature):
    """
    情绪逆向策略
    """
    if temperature < 20:
        return {
            "action": "重仓买入",
            "position": 0.8,  # 80%仓位
            "reason": "极度恐惧，贪婪买入时刻"
        }
    elif temperature < 35:
        return {
            "action": "逐步买入",
            "position": 0.6,
            "reason": "市场恐惧，逐步建仓"
        }
    elif temperature < 65:
        return {
            "action": "持有观望",
            "position": 0.5,
            "reason": "情绪中性，保持仓位"
        }
    elif temperature < 80:
        return {
            "action": "逐步卖出",
            "position": 0.3,
            "reason": "市场乐观，获利了结"
        }
    else:
        return {
            "action": "清仓离场",
            "position": 0.1,
            "reason": "极度贪婪，恐惧逃顶"
        }
```

## 风险提示

> [!CAUTION]
> 1. 情绪指标是辅助工具，不是唯一决策依据
> 2. 极端情绪可能持续较长时间
> 3. 需要结合估值、基本面综合判断
> 4. 历史规律不保证未来重复
