# 投资大师智慧精华

> 融合百年投资大师的核心投资哲学与实践智慧

## 巴菲特 (Warren Buffett)

### 核心原则

1. **买股票就是买公司**
   - 不要把股票当作交易筹码
   - 要像买入整个公司一样思考
   - 关注企业的内在价值

2. **能力圈原则**
   - 只投资自己能理解的生意
   - 宁可错过，也不盲目投资
   - 扩大能力圈需要时间和学习

3. **安全边际**
   - 以显著低于内在价值的价格买入
   - 安全边际是投资成功的基石
   - 建议安全边际 ≥ 30%

4. **护城河思维**
   - 寻找具有持久竞争优势的企业
   - 护城河类型：品牌、成本、网络效应、转换成本
   - 护城河要足够宽、足够深

5. **长期持有**
   - "我们最喜欢的持有期限是永远"
   - 频繁交易是财富的敌人
   - 复利是世界第八大奇迹

### 实战应用

```python
# 巴菲特式买入条件
def buffett_buy_signal(stock):
    return (
        stock.pe_percentile < 30 and      # 估值低于历史30%分位
        stock.roe > 15 and                 # ROE > 15%
        stock.moat_score >= 20 and         # 护城河评分 ≥ 20/30
        stock.understand == True           # 能理解这个生意
    )
```

## 段永平 (Duan Yongping)

### 核心原则：Right Business, Right People, Right Price

1. **Right Business (好生意)**
   - 生意模式简单易懂
   - 具有持续的现金流
   - 有定价权
   - 消费者心智中有位置

2. **Right People (好管理层)**
   - 诚信是第一位的
   - 有能力且专注
   - 与股东利益一致
   - 长期主义思维

3. **Right Price (好价格)**
   - 不为好公司付出过高价格
   - "好生意+好价格"才是好投资
   - 等待市场给出好价格的机会

### 段永平金句

- "买股票就是买公司，买公司就是买它的未来现金流折现"
- "不懂不做，这是底线"
- "做对的事情，把事情做对"
- "本分：做对的事情，不占便宜"

### 实战应用

```python
# 段永平式投资检查清单
def duan_checklist(stock):
    score = 0
    
    # Right Business
    if stock.business_model == "简单易懂":
        score += 1
    if stock.free_cash_flow > 0:
        score += 1
    if stock.has_pricing_power:
        score += 1
    
    # Right People
    if stock.management_integrity:
        score += 1
    if stock.management_capability:
        score += 1
    
    # Right Price
    if stock.pe < stock.industry_median_pe:
        score += 1
    if stock.pe_percentile < 40:
        score += 1
    
    return score >= 5  # 至少5分才考虑
```

## Howard Marks

### 核心原则

1. **周期思维**
   - 万物皆有周期
   - 理解你在周期中的位置
   - 周期的极端不会永远持续

2. **二层思维 (Second-Level Thinking)**
   - 一层思维："这是一家好公司，买入"
   - 二层思维："这是好公司，但大家都知道，所以价格高，卖出"
   - 超额收益来自与众不同且正确

3. **风险思维**
   - 风险不是波动，而是永久损失的可能
   - 承担已知风险以获取收益
   - 最大的风险是你不知道自己不知道什么

4. **逆向投资**
   - 在别人恐惧时贪婪
   - 买入时要有"不舒服"的感觉
   - 羊群心理是投资的大敌

### 周期定位框架

```
  乐观情绪峰值
        ↓
    贪婪 ────┐
             │
    乐观 ────┤   ← 考虑卖出
             │
    中性 ────┤   ← 持有观望
             │
    悲观 ────┤   ← 开始买入
             │
    恐惧 ────┘   ← 积极买入
        ↑
  悲观情绪谷底
```

### 实战应用

```python
# Howard Marks式周期定位
def marks_cycle_position(market):
    score = 0
    
    # 估值维度
    if market.pe_percentile < 20:
        score += 2  # 极度低估
    elif market.pe_percentile < 40:
        score += 1  # 低估
    elif market.pe_percentile > 80:
        score -= 2  # 高估
    
    # 情绪维度
    if market.sentiment < 25:
        score += 2  # 恐惧
    elif market.sentiment > 75:
        score -= 2  # 贪婪
    
    # 资金维度
    if market.margin_change < -5:
        score += 1  # 资金离场
    elif market.margin_change > 10:
        score -= 1  # 资金过热
    
    if score >= 3:
        return "周期底部，积极买入"
    elif score >= 1:
        return "周期低位，可以买入"
    elif score <= -3:
        return "周期顶部，准备卖出"
    elif score <= -1:
        return "周期高位，谨慎"
    else:
        return "周期中部，持有观望"
```

## 格雷厄姆 (Benjamin Graham)

### 核心原则

1. **市场先生理论**
   - 市场是你的仆人，不是你的主人
   - 市场先生情绪不稳定
   - 利用市场先生的情绪，而不是被其影响

2. **安全边际**
   - "投资成功的秘诀在于安全边际"
   - 以低于内在价值的价格买入
   - 安全边际越大越好

3. **保守估值**
   - 使用保守的假设进行估值
   - 不要相信过于乐观的预测
   - 关注净资产和盈利能力

### 格雷厄姆公式

```
内在价值 = EPS × (8.5 + 2g)

其中：
- EPS = 每股收益
- 8.5 = 零增长公司的合理PE
- g = 预期5年年均增长率(%)
```

## 芒格 (Charlie Munger)

### 核心原则

1. **多元思维模型**
   - 跨学科思考
   - 避免"铁锤人"综合症
   - 融合多种思维模型

2. **逆向思考**
   - "如果想知道如何幸福，先思考如何不幸"
   - 避免愚蠢比追求聪明更重要
   - 检查清单思维

3. **能力圈**
   - 知道自己不知道什么
   - 保守地估计能力圈边界
   - 不断学习扩大能力圈

4. **检查清单**
   - 使用检查清单避免盲区
   - 系统化决策流程
   - 避免心理偏差

### 芒格检查清单

```markdown
## 投资前的芒格检查清单

### 避免的陷阱
- [ ] 是否有确认偏误？（只看支持观点的证据）
- [ ] 是否受近因效应影响？（过度关注近期表现）
- [ ] 是否有从众心理？（因为别人买而买）
- [ ] 是否有锚定效应？（被某个价格锚定）
- [ ] 是否过度自信？

### 必须确认
- [ ] 我真的理解这个生意吗？
- [ ] 如果我错了，会损失多少？
- [ ] 有更好的选择吗？
- [ ] 我是在投资还是投机？
```

## 达利欧 (Ray Dalio)

### 核心原则

1. **风险平价**
   - 平衡各类资产的风险贡献
   - 不依赖单一资产类别
   - 分散化是唯一免费的午餐

2. **全天候策略**
   - 适应各种经济环境
   - 股债商品多元配置
   - 动态再平衡

3. **原则驱动**
   - 将决策过程系统化
   - 从错误中学习并记录原则
   - 建立可重复的决策框架

### 全天候组合

```
经济增长超预期    经济增长低于预期
    ↓                  ↓
┌─────────┐      ┌─────────┐
│ 股票    │      │ 债券    │
│ 商品    │      │ 黄金    │
└─────────┘      └─────────┘

通胀超预期        通胀低于预期
    ↓                  ↓
┌─────────┐      ┌─────────┐
│ 商品    │      │ 股票    │
│ 黄金    │      │ 债券    │
└─────────┘      └─────────┘
```
