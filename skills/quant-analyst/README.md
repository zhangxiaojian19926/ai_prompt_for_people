## 🌟 最佳实践工作流 (The Golden Workflow)

作为一个理性的量化投资者，建议按照以下**四步走**流程使用本系统：

### Step 1: 宏观定势 (Market Context)
**目标**: 判断当前是"贪婪"还是"恐惧"时刻，决定仓位轻重。

运行市场风向标，重点关注 **ERP (股权风险溢价)**：
```bash
python scripts/market_indicator.py
```
> **⬇️ 预期输出**:
> ```text
> [宏观风向标]
> 10年国债收益率(Rf): 2.30%
> 股权风险溢价 (ERP): 3.15%  <-- 极具价值
> --------------------------------
> 沪深300 PE: 11.5 (历史分位 20%)
> 创业板指 PE: 28.5 (历史分位 15%)
> ```

- **🟢 ERP > 3%**: 市场低估，积极做多（建议仓位 80%+）
- **🟡 0% < ERP < 3%**: 估值合理，正常轮动（建议仓位 50%）
- **🔴 ERP < 0%**: 市场泡沫，警惕风险（建议仓位 <30%）

---

### Step 2: 智能选股 (Smart Selection)
**目标**: 在茫茫股海中筛选出"好行业、好公司、好价格"。

运行多因子选股器，寻找**高ROE+低估值+上涨趋势**的标的：
```bash
python scripts/multifactor_screener.py
```
> **⬇️ 预期输出**:
> ```text
> 正在扫描...
> ====== 多因子选股结果 (Top 3) ======
> symbol  name      score   pe    roe    trend
> 600519  贵州茅台   80     25.1  28.5   bull
> 000858  五粮液     70     18.2  22.1   bear
> 300750  宁德时代   65     20.5  18.2   bull
> ```

**筛选标准**:
- 💎 **质量**: ROE > 15% (巴菲特门槛)
- 💰 **价值**: PE < 35, PEG < 1.5
- 🚀 **成长**: 营收/净利增长 > 10%
- 📈 **动量**: 股价站上60日均线

---

### Step 3: 深度透视 (Fundamental Check)
**目标**: 对筛选出的目标进行"体检"，确认财务健康。

使用Python脚本深入查询个股详情（以贵州茅台为例）：
```python
from data_fetcher import DataFetcher
df = DataFetcher()
print(df.get_stock_valuation("600519"))
```
> **⬇️ 预期输出**:
> ```python
> {
>   "symbol": "600519",
>   "name": "贵州茅台",
>   "pe_ttm": 25.1,
>   "roe": 28.5,            # 高ROE，质量优秀
>   "revenue_growth": 15.2, # 营收稳健增长
>   "peg": 1.3              # 估值相对合理
> }
> ```
关注 **营收增速** 和 **净利率** 是否匹配其估值。

---

### Step 4: 策略验证 (Strategy & Risk)
**目标**: 制定交易计划，设置风控底线。

在买入前，先跑一遍回测，看看策略在历史上的表现，并设定 **ATR止损位**：
```bash
# 对目标股票运行均线策略，并设置2倍ATR止损
python scripts/backtest.py --symbol 600519 --strategy ma_cross --stop-loss-atr 2.0
```
> **⬇️ 预期输出**:
> ```text
> [回测报告] 贵州茅台 (MA Cross + ATR风控)
> ----------------------------------------
> 总收益率: 15.6%   (基准: -5.2%)
> 最大回撤: 12.5%   (优化前: 28.3%)  <-- 风控效果显著
> 交易次数: 8次
> ----------------------------------------
> [最新信号]
> 2024-07-23: ATR止损触发 (卖出价: 1450.00)
> 下一个ATR止损位: 1380.50
> ```

- 如果回测显示 **Max Drawdown (最大回撤)** 超过你的承受力，请放弃或降低仓位。
- 记住脚本生成的 **ATR止损价**，作为你的硬性离场点。

## 🛡 核心机制与设计哲学 (Why It's Reliable)

本系统并非简单的脚本堆砌，而是基于"百年资深投资者"审计建议构建的严谨工程。

### 1. 数据可靠性：三重熔断机制
我们深知数据的准确性是量化的基石。系统采用多层级数据保障策略：
- **Layer 1 (首选)**: `AKShare` 官方接口（实时性强，覆盖全）。
- **Layer 2 (备选)**: 浏览器MCP接口（模拟用户浏览，作为交叉验证）。
- **Layer 3 (兜底)**: 本地缓存/静态估算（确保极端网络环境下程序不崩溃，并给出明确警告）。
> *并在底层实现了指数退避重试 (Exponential Backoff)，自动处理网络抖动。*

### 2. 也是理论基础：融合大师智慧
- **格雷厄姆 (安全边际)**: 通过 `ERP` 和 `PE百分位` 寻找低估值区间。
- **巴菲特 (护城河)**: 通过 `ROE > 15%` 和 `净利率` 筛选优质企业。
- **技术派 (顺势而为)**: 通过 `MA60` 和 `ATR` 确保不接飞刀，不做逆势交易。

### 3. 风控体系：不仅是代码
我们在每一笔模拟交易中都强制植入了风控基因：
- **ATR动态止损**: 止损位根据市场波动率动态调整，而非僵化的固定比例。
- **仓位管理**: 根据 `ERP` 水位自动建议仓位上限（如ERP<0%时建议<30%仓位）。

## 💡 典型实战案例 (Typical Scenarios)

### 场景 A: 熊市底部的左侧布局者
- **情境**: 市场连续下跌，周围一片哀嚎。
- **操作**: 
  1. 运行 `python scripts/market_indicator.py`
  2. 发现 **ERP > 4%** (极具价值) 且 **沪深300 PE < 20%分位**。
  3. 执行: **买入宽基指数ETF (如沪深300ETF)**，仓位提升至 80%。
- **结果**: 获取了周期底部的廉价筹码，等待均值回归。

### 场景 B: 震荡市的成长股猎手
- **情境**: 大盘指数横盘，寻找结构性机会。
- **操作**:
  1. 运行 `python scripts/multifactor_screener.py`
  2. 筛选出 **ROE > 20%** 且 **净利增长 > 20%** 的公司（如宁德时代、迈瑞医疗）。
  3. 进一步查看其 **PEG < 1.0** (估值未被透支)。
  4. 执行: **构建成长股组合**。
- **结果**: 跑赢大盘，享受业绩增长带来的Alpha收益。

### 场景 C: 牛市中途的顺势交易者
- **情境**: 市场已经上涨一段，担心回调但怕踏空。
- **操作**:
  1. 选定目标股，运行回测 `python scripts/backtest.py --strategy ma_cross --stop-loss-atr 2.0`。
  2. 发现策略胜率不错，且ATR止损能控制最大回撤在 10% 以内。
  3. 执行: **买入并持有**，同时每日更新 ATR 止损价。
  4. **关键**: 当某天收盘价跌破止损价时，**坚决卖出**，保住胜利果实。
